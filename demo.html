🚀 How to Access:

Option 1: Local Access
If you're running this on your computer:

1. Make sure Flask is running: python app.py
2. Open browser to: http://localhost:5000
3. Enjoy the UFO interface!

Option 2: Command Line
Use the CLI for full functionality:

# List all genres and artists
python main.py list

# Upload and organize a beat
python main.py organize beat.mp3 hip-hop

# Send beats to artists
python main.py send --genre hip-hop

💡 Quick Test
